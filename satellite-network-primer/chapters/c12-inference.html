Section 10.1 derives ring all-reduce traffic of \(2(N-1)/N\) times model bytes per worker per step. Section 9.4 lists flown single-satellite inference.
第 10.1 節推導過環狀 all-reduce 每步每個工作節點要搬運 \(2(N-1)/N\) 倍的模型位元組，第 9.4 節列出了已經飛過的單衛星推論。

Chapter 10 finds constellation links three to five orders too slow per compute element for training. Inference has different traffic requirements. A decoder-only transformer serves requests in two phases. prefill processes all prompt tokens through every layer in one parallel sweep. Each output tensor has one row per prompt token. decode emits one output token per step, using the previous output, so each layer sends one row.

Thus, the tensor that leaves a layer has a single row. Each attention layer stores the keys and values of earlier tokens for reuse during decode in a KV cache. The cache grows by one entry per layer per generated token and is read in full at every step. The quantity a serving system minimizes is the time per token, the wall-clock time one decode step takes for one request stream. It plays the role step time played in Chapter 10, with the same two-term structure of compute plus exposed communication.

第 10 章拿星座去對照訓練，發現每個運算元件分到的鏈路慢了三到五個數量級。推論問的是另一個問題，差異來自跨越網路的資料內容。對一個 decoder-only transformer 服務一個請求有兩個階段。在預填（prefill）階段，提示中的每個 token 以一次平行掃過的方式通過所有層，因此離開某一層的張量每個提示 token 占一列。而在解碼（decode）階段，模型每一步輸出一個 token、每一步都以前一步為輸入，因此離開某一層的張量只有一列。

為了避免每個解碼步驟重算整段提示，每個注意力層把它為先前每個 token 算出的 key 與 value 留在KV 快取裡，這個快取每產生一個 token 就在每一層多一筆，而且每一步都要整個讀一遍。服務系統要最小化的量是每 token 時間，也就是單一請求串流中一個解碼步驟所需的時鐘時間。它扮演第 10 章中步驟時間的角色，同樣由運算加上暴露的通訊這兩項組成。

解碼在每個層邊界傳送一個隱藏向量，預填則為每個提示 token 各傳一個。KV 狀態跨層累積，搬移量因而更大。

The KV cache’s location determines the system’s data paths. The satellite that prefills its attention layers stores the cache, adds 0.5 MB per generated token, and releases it when the request ends. Moving KV costs more than moving the activation across a boundary. In this architecture, one token’s KV is sixty-four times its activation. A whole context requires gigabytes.

Figure 12.1 draws the two phases side by side and marks the one place where the traffic is heavy, which is the prefill sweep. The one place where state accumulates, which is the KV store on the attention satellite. The evaluated systems keep KV at its creation site. SkyMemory proposes remote KV caching, whose transfer cost remains open. Section 12.6 returns to what that implies for serving ground users.

KV 快取的位置決定了系統的資料路徑。執行相應注意力層預填的衛星保存快取，每產生一個 token 增加 0.5 MB，請求結束時釋放。相對於跨越邊界的激活值，搬動它是成本較高的，因為在這個架構下一個 token 的 KV 是一個 token 激活值的六十四倍，而搬一整段上下文意味著搬動數 GB。圖 12.1 把兩個階段並排畫出，標出流量唯一沉重的地方（預填掃過）與狀態唯一累積的地方（注意力衛星上的 KV 儲存）。本章每個系統要麼讓 KV 留在它誕生的地方，要麼像 SkyMemory 那樣提議把它快取到其他位置，傳輸成本則待量化。第 12.6 節會回到這對服務地面使用者意味著什麼。

Two-level expert placement minimizes the expected path traveled by a token’s hidden state. First, each MoE layer receives a contiguous ring-based satellite subnet with a central gateway (Eqs. 17–18). Tokens cross layers by hopping between neighboring subnets. Second, activation frequency assigns experts within each subnet (Eqs. 19–20, 29–30), minimizing expected per-layer latency (Eqs. 33–34).

Theorem 1 assigns the \(i\)-th most frequently activated expert to the \(i\)-th lowest-latency satellite. This optimum takes \(O(I\log I + V\log V)\) per layer. Figure 12.2 illustrates the scheme.

Across eight lm-eval-harness datasets, SpaceMoE reports 1.02–1.07 s per token. Random placement within a contiguous region achieves 3.34–3.37 s. Random intra-orbit placement takes 4.13–4.16 s, and fully random placement takes 5.28–5.30 s (Table II, Figs. 6–7).
